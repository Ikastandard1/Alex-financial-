APEX MARKET INTELLIGENCE — NETLIFY PACKAGE

HOW TO USE
1. Unzip this folder.
2. Open the folder and drag the whole folder into Netlify Drop.
3. Netlify will publish index.html automatically.

WHAT IS INCLUDED
- index.html — complete responsive website
- styles.css — desktop + mobile design
- script.js — animated candlestick chart, live-looking market updates and mini charts

IMPORTANT ABOUT "REAL DATA"
The candlestick chart is built to behave like a live market chart, but this static demo does NOT pretend that random values are a real exchange feed.

For genuine live USOIL / S&P 500 prices, you need a market-data provider/API with the appropriate market-data rights (for example Twelve Data, Finnhub, Polygon, or another licensed provider). A public Netlify page should not contain a private API secret.

The chart/data layer is intentionally separated so a real API/WebSocket can be connected later without redesigning the site.
